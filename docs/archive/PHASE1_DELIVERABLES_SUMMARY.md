## API Examples

### 1. Detect Repository
```bash
curl -X POST http://localhost:5000/api/repo/detect \
  -H "Content-Type: application/json" \
  -d '{"repo_path": "./generated/my-app"}'
```

**Response:**
```json
{
  "status": "success",
  "detection_report": {
    "languages": {...},
    "build_commands": {"confident": ["npm install"]},
    "run_commands": {"confident": ["npm run dev"]}
  },
  "artifactPath": ".sb_artifacts/detection_report_20250114T120000Z.json"
}
```

### 2. Grant Permission
```bash
curl -X POST http://localhost:5000/api/session/permissions \
  -H "Content-Type: application/json" \
  -d '{
    "session_id": "session-123",
    "actions": ["allow_build", "allow_run"],
    "commands": ["npm install", "npm run dev"],
    "duration": 3600
  }'
```

### 3. Launch Instance
```bash
curl -X POST http://localhost:5000/api/app/launch \
  -H "Content-Type: application/json" \
  -d '{
    "app_path": "./generated/my-app",
    "port": 3000,
    "cpu_limit": 1.0,
    "memory_limit": "512m",
    "timeout": 3600
  }'
```

**Response (Success):**
```json
{
  "status": "success",
  "instance_id": "inst_abc123",
  "preview_url": "http://localhost:3000",
  "session_token": "tok_xyz...",
  "expires_at": "2025-01-14T13:00:00Z",
  "logs_url": "/api/sandbox/inst_abc123/logs"
}
```

**Response (Permission Required):**
```json
{
  "error": "permission_required",
  "message": "Please grant permission to run builds/containers.",
  "requiredCommands": ["npm install", "npm run dev"],
  "sessionId": "session-123"
}
```

### 4. Get Audit Log
```bash
curl http://localhost:5000/api/audit/run_20250114T120000Z_abc123
```

**Response:**
